
**建议时长 8–10 分钟。** 同小济还没正式入学，第一次来到同济大学计算机科学与技术学院。他本来只想问清楚三件事：实验室在哪，研究生怎么选课，以及为什么找同一个学院的人要跑两栋楼。走完这一趟，他把自己的入学前经历想成了一个 Agent 项目，并在公告栏发出第一封招募帖。

**加倍速后尽量3分钟左右**

## 人物介绍


| 人物 | 在故事里的作用 |

| --- | --- |

| **同小济** | 玩家操控的研零新生。想提前熟悉实验室和课程，担心自己没做过 Agent 项目，跟不上实践课。 |

| **噜噜** | 同小济的同门师兄，也是主线引路人。嘴上说「不是，诶不对等等，我再想想」，转头就替师弟把去哪儿、找谁问清楚了。 |

| **自嘲熊** | 爱吃也爱自嘲的研一学姐。用自己的新生糗事缓解同小济的紧张，也可以作为观察 NPC 自主活动和公告阅读的对象。 |

| **周可可** | 细致务实的研一学姐。适合聊第一学期怎么选课，以及如何把大项目拆成能做完的小实验。 |

| **圣聆初雪** | 熟悉校园的研二学姐，负责解开同小济关于两栋楼的疑问。 |

| **温言老师** | 熟悉 Agent 的女副导师。帮同小济从自己今天的经历里找到项目题目，并鼓励他招募伙伴。 |

  

开场可用角色状态栏带过阿沫、辍学熊、严正老师和担任教务秘书的钱管老师。口头介绍重点放在噜噜、自嘲熊、周可可、圣聆初雪和温言。

  

演示称呼按这版人设统一。圣聆初雪、周可可、自嘲熊是学姐，温言和钱管是女老师，其余 NPC 为男性。

  

## 演示流程与剧情

  

### 第一幕 · 同小济还没来，校园已经开始运转（约 1 分钟）

  

**旁白**

  

> 今天是同小济第一次来学院。人还没进实验室，学长学姐们已经开始忙了。我们先看看，校园里平时都在发生什么。

  

**操作**

  

1. 以旁观模式开场，切换济事楼三楼、四楼和智信馆二楼。

2. 用左侧状态栏跟随自嘲熊，展示她的位置、当前活动和事件时间线。她正忙时，可以切到另一名正在走动的 NPC 展示寻路。

3. 打开一段已经发生的 NPC 对话或阅读事件，查看经过和个人记忆。如果现场正发生自主对话，可顺势展示气泡。

  

这一幕让观众看见，玩家加入之前，NPC 已经在按各自的日程行动。

  

### 第二幕 · 在济事楼找到同门师兄（约 2 分钟）

  

加入玩家模式，以「同小济」进入校园。用状态栏找到噜噜，走近后按 **E** 交谈。

  

如果先遇到自嘲熊，可以让同小济问一句「学姐，第一次来实验室怎么找人？」。自嘲熊的参考回应是「我刚来那会儿，把去茶水间的路记得比工位还熟。你找噜噜？先看看他在哪层，省得跟我一样跑两趟。」

  

**同小济现场输入**

  

> 噜噜师兄好！我是还没正式入学的同小济。第一学期选课，我应该先看培养方案，还是先问问组里大家都选了什么？

  

**噜噜的参考回应**

  

> 先看培养方案，必修和学分弄清楚，再来问我们哪些课跟你想做的方向有关。对了，你对大模型感兴趣的话，可以问问周可可学姐。前两天还听见大家聊《大模型与智能体技术》。

  

**操作与观察**

  

- 开聊后噜噜停下来，镜头和对话框切入交谈视角。

- 如果有另一名 NPC 来找噜噜，可以给等候者一个镜头。结束玩家交谈后，再看它的邀约继续处理。

- 现场固定同小济输入的话。NPC 台词由模型生成，演示员按回复的意思接话。

  

### 第三幕 · 一张公告把新生带到智信馆（约 2–3 分钟）

  

同小济问完噜噜，以为下一站还在济事楼。走廊公告却提示，想了解课程项目的同学可以去智信馆看看。用上帝模式发布演示公告，或使用事先发好的公告。随后走到栏前，按 **E** 查看。

  

**演示用公告**

  

> 【新生选课交流】对《大模型与智能体技术》感兴趣的同学，可以到智信馆二楼参与项目交流。带一个你希望智能体解决的小问题来。第一次接触 Agent 的同学也欢迎参加。

  

如果有 NPC 经过同一走廊，可以跟随它，看状态从「走近公告栏」变成「阅读公告」，再在时间线上找到阅读记录。

  

同小济走到跨馆入口，按 **E** 前往智信馆二楼，去找圣聆初雪。

  

**同小济**

  

> 学姐，我今天找了一圈，济事楼是计算机学院，智信馆也能碰到计算机学院的人。这是怎么回事？

  

**圣聆初雪的参考回应**

  

> 同济计算机学科的历史比现在这个学院的名字长得多。2024 年 9 月 19 日，学校整合原计算机科学与技术系和原软件学院，成立了现在的计算机科学与技术学院，也保留了软件学院的牌子。学院公布的机构信息里，实验中心在济事楼和智信馆都有办公点。 [同济大学学院介绍](https://cs.tongji.edu.cn/xygk/xyjs.htm) · [学院机构设置](https://cs.tongji.edu.cn/xygk/jgsz.htm)

  

NPC 若只回答了部分内容，旁白接着讲学院沿革。两馆之间的通行路线和人物分布按游戏场景呈现。

  

### 第四幕 · 从「我能选这门课吗」到「我可以做什么」（约 2 分钟）

  

在智信馆与周可可交谈。从新生的选课顾虑聊起，把课程内容落到刚体验过的一件小事上。

  

**同小济**

  

> 学姐，《大模型与智能体技术》是谁讲的？这门课主要做什么？

  

**周可可的参考回应**

  

> 程鹏老师和宋井宽老师开了这门实践课。智能体技术变化快，课上会让大家亲手做一个 Agent 项目，看看它怎么感知、记忆和行动。

  

**同小济追问**

> 我还没做过 Agent 项目呢，不知道做什么比较好。

**周可可的参考回应**

> 你可以去找温言老师请教。她对 Agent 比较熟悉，也愿意帮刚入门的同学一起想题目。把你今天第一次逛学院的经历讲给她听，看看她有什么建议。

课程段落沿用演示方提供的背景。正式课名、授课安排和学期，定稿时以课程大纲为准。两位老师的团队背景可查阅同济空间智能团队成员页。 [同济空间智能团队](https://sig.tongji.edu.cn/_upload/tpl/07/b1/1969/template1969/member.html)

  

### 尾声 · 同小济发出第一封招募帖（约 2 分钟）

结束和周可可的交谈，在角色状态栏查看温言老师的位置。她在济事楼时，从智信馆的跨馆入口按 **E** 返回，再走到她身边开启交谈。

**同小济现场输入**

> 温言老师好！我是还没入学的同小济。今天第一次来学院，我跑了济事楼和智信馆，问了学长学姐怎么选课，也看了走廊里的公告。周可可学姐建议我来找您。我想做个 Agent 项目，还没想好做什么，您有什么建议吗？

**温言老师的参考回应**

> 那就把你今天的经历做成一个 Agent 交互项目吧。让里面的角色过一过我们同济计算机的校园生活，有人去实验室，有人遇到同学停下来聊几句，还有人路过公告栏看看新消息。
>
> 你也可以把这个点子写在公告栏上，和大家分享一下。我相信学长学姐和老师们都会愿意来报名，扮演里面的 NPC。

**同小济发布招募帖**

离开对话，走到公告栏。打开「上帝模式」，选择当前楼层的公告栏，输入并发布下面这条招募帖。发布后再次打开公告栏，让观众看到同小济的帖子，再切回校园全景。

> **PixelTJCS：像素同济计算机——基于多智能体自主交互的像素校园模拟系统**
>
> 大家好，我是还没正式入学的同小济。今天第一次来学院，我在济事楼找师兄，在智信馆问学姐怎么选课，最后跟温言老师聊出了一个点子。我想把今天做成一座像素校园，让角色自己安排日程、遇到同学聊天、走到公告栏前看消息。如果你愿意来扮演其中一位 NPC，欢迎报名。也欢迎告诉我，你想让这个角色在校园里做什么！

## 排练清单

  

- **必演**。旁观 NPC 自主活动、加入玩家后与噜噜交谈、跨馆后向周可可和温言老师请教，最后发布 PixelTJCS 招募帖。

- **提前留证据**。在演示存档中留一段 NPC 自主对话和一条实际完成的公告阅读记录。现场有 NPC 自动阅读或到旁边等候时，就顺势展示。

- **核对走位**。开场前用状态栏确认噜噜、周可可、圣聆初雪和温言的位置。想让周可可在智信馆出场，可以提前用悄悄话指派其前往图书分馆。温言在其他楼层时，跟着状态栏确认路线。提前确认尾声准备使用哪个公告栏。
