# Roamchestra 🏫 — 校园多智能体交互系统

以 **NPC↔NPC 自主交互**为核心的校园多智能体课程大作业系统。
场景设定在同济大学校园（济事楼三楼、四楼与智信馆二楼），7 名学生 + 3 名导师/教务
NPC 在里面自主对话、积累记忆、互相遗忘、发展关系。

> 本项目基于 Helloagents-AI-Town 的问题意识重新实现：
> 基座的"NPC 对话"是互不相关的批量独白；这里让 NPC 真正感知彼此、
> 双向对话、把经历写进自己的记忆，并随时间**可视化地遗忘**。

## 核心特性（已实现）

- 🎭 **人格卡驱动**：每个角色一张 JSON 卡（性格/目标/秘密/日程），改卡即改人
- 💬 **真·双向对话**：发起 → 多轮往返 → 双方以各自视角沉淀记忆
- 🧠 **自研记忆系统**：向量检索（新近度×重要性×相关度三因子打分）
- 🫥 **可视化遗忘**：时间衰减 / 容量淘汰 / 反思压缩三机制，全部留痕可查询
- ❤️ **关系网络**：每次对话后 LLM 评估好感度变化（带原因）
- ⏩ **连续快进**：原速为现实 1 秒对应游戏 10 分钟。支持 ×1／×2／×4／×6 和定时快进 1 小时、4 小时或 3 天。定时快进结束后恢复原倍率，时钟、移动与动画同步加速。
- 🗺️ **校园寻路**：10 个 NPC 在三张楼层图的 40 个区域间活动，按实际地板和障碍物寻路。运行 Godot 主场景，按 1、2、3 切换观察楼层，空格跟随 NPC，V 查看分区和当前行走目标。
- 🚶 **可行走玩家**：默认关闭。加入后用 WASD／方向键行走。看到「按E交互」时，按 E 与白边标出的 NPC 交谈或查看告示栏。走到楼梯箭头即可换层，P 回到自己。右下角可查看机制说明。

### M6 交互与事件系统

- **角色状态栏与事件时间线**。查看每位角色的位置和当前活动，悬停临时跟随，点击定位并打开资料。事件时间线保存实际经过、角色判断、后续动作和调度原因。
- **事件驱动的自主行动**。模型可根据活动结果或对话决定找人、去某地做事、延长活动或继续原安排。调度按基础日程、自主响应和玩家指派三档处理。找人追踪实际位置，双方到位后发起邀约，对话期间站定并按顺序显示气泡。
- **公告与旁听记忆**。NPC 实际读完公告后形成个人记忆。在同一房间或走廊内，距说话者 150 地图像素以内的旁听者可以记住听到的片段。角色回忆可以带有个人推测，事件保留实际台词和公告原文。
- **上帝模式**。集中发布及删除公告、查看历史、用悄悄话指派行动、控制 NPC 退场或出演，以及确认后重置世界。 [M6 功能与代码交接](docs/M6.md)

## 运行方式

- **NPC 自主运行**：连接后端后，NPC 按日程移动、相遇交谈、阅读公告并产生事件和记忆；玩家身份默认关闭。有模型密钥时可使用模型决策，无密钥时使用降级行为。
- **玩家加入**：在同一个持续运行的世界中加入可行走的玩家，靠近 NPC 交谈或查看公告。NPC 的自主活动仍继续；上帝模式可额外发布公告、悄悄话指派行动、控制角色退场和重置世界。
- **仅前端离线演示**：后端未连接时显示本地 NPC 演示日程，不能验证真实模型交谈或玩家会话。

## 快速开始

Windows 上可双击根目录的 `Start-Roamchestra.bat`。首次使用时，将 `launcher.local.bat.example` 复制为 `launcher.local.bat`，把 `ROAMCHESTRA_PYTHON` 指向当前 Python 或 Conda 环境的 `python.exe`，把 `GODOT_EXE` 指向 Godot 可执行文件。此本机配置不会提交到 Git。若已激活 Conda 环境或项目内有 `.venv`，Python 路径可以不填；若 Godot 在 PATH 中，Godot 路径也可以不填。脚本先启动后端，健康检查通过后打开 Godot，关闭游戏窗口后停止本次启动的后端。

前端默认连接 `http://127.0.0.1:8000`。后端在另一地址时，运行 Godot 前设置 `ROAMCHESTRA_BACKEND_URL`（如 `http://服务器地址:8000`）；HTTP 和 WebSocket 会使用同一地址。

`scripts/run_demo.py` 是单独的命令行演示，会初始化运行数据库。带存档的日常启动使用双击脚本或手动启动双端。

```bash
cd Roamchestra
pip install -r requirements.txt
copy .env.example .env       # 填入你的 API key
# 可选的命令行演示（会初始化运行数据库）：python scripts/run_demo.py
uvicorn backend.api:app --port 8000   # HTTP 接口（文档在 /docs）

# 5) 跑 Godot 前端（可独立观察 NPC；玩家聊天需连接后端）
#    ① 下载 Godot 4.5.2 stable 标准版（不是 .NET 版）: godotengine.org/download/archive/
#    ② 双击 exe（绿色免安装）→ 项目管理器选"导入" → frontend/project.godot
#    ③ 编辑器里按 F5 运行（详细说明与排错见 docs/CODE_GUIDE.md §7）
#    ④ 双端联调: 终端 A 先起 uvicorn backend.api:app --port 8000，再 F5 →
#       右上角显示"后端驱动" = NPC 按后端日程移动；
#       后端不在线时前端自动回退本地演示日程，永不白屏
#    ⑤ 玩家模式：点击顶部按钮加入；WASD/方向键行走，按 E 交互，踩楼梯箭头换层，P 回到自己
```

Windows PowerShell 建议用 Python 3.11 的独立环境安装；若系统默认 GBK 编码，`-X utf8` 可正常读取依赖文件中的中文注释：

```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\python.exe -X utf8 -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -X utf8 -m uvicorn backend.api:app --host 127.0.0.1 --port 8000
```
