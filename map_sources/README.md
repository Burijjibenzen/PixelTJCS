## 图层、碰撞与交互

三张地图共划分 **40 个区域**，其中济事楼三楼、四楼各 9 个，智信馆二楼 22 个。每个房间的地板独立成层，同层连通的走廊共用一层。每个图层对应楼层目录 `layers/` 下的一个 `.tscn` 文件，可单独编辑。程序直接读取地板图层确定分区。

| 图层 | 放什么 | 人物能否通过 |
| --- | --- | --- |
| `room_*` | 房间和走廊的地板。家具下方也保留地板，以便判断房间归属。 | 地板可走，叠有墙或家具的位置由对应的碰撞层决定。 |
| `wall`、`obstacle*` | 墙和固定隔断放 `wall`，桌体、椅座、花盆底座等落地物件的占地放 `obstacle`。济事楼另有 `obstacle_storage` 放柜体。 | 墙和实体占地挡路。 |
| `zhuangshi*` | 地毯、墙饰、桌面小物，以及伸出花盆底座的叶尖。 | 装饰本身不挡路。人物可走过地毯、擦过叶尖，桌上的书由下方桌体挡住。 |
| `door` | 门扇单独一层，墙层在门洞处留空。 | 试走时关门挡路、开门通行。 |
| `interactable*`、`stair`、`spawn` | 分别放可交互物件、楼梯和出生点标记。 | 这些层本身不增加固定碰撞。落地设备需要挡人时，将实体占地同时标在障碍层。 |

改图时，`wall` 和 `obstacle*` 开启碰撞，其余层关闭。Godot 的物理碰撞读取图层的碰撞开关，试走网格根据障碍层名生成，修改时要同时核对。门的通行范围和物件的交互位置记录在对应楼层的 `manifest.json` 中。[地图分层规范](../docs/MAP_SPEC.md)

- **浏览与试走**　在 Godot 4.5 中可以切换楼层、缩放和平移地图，点击地面可高亮所在房间或走廊。试走时可用方向键或 WASD 移动。已清理门口误挡和家具堵住的过道，并限制起点只能选在可达位置，避免人物落入孤立地格。
- **门与楼梯**　点击门或走近按 `E` 可开关门。济事楼三、四楼可通过东、西两处楼梯往返，同一次浏览中切换楼层会保留各扇门的开关状态。
- **物件与公告栏**　可点击或走近按 `E` 查看电脑、书架、讲座黑板、讲台、健身器材和公告栏。济事楼三、四楼的西侧走廊各有一块公告栏，智信馆二楼仅在图书分馆保留一块。三块均预留给后续学院通知，当前只显示「公告栏」。

## 查看与改图

用 Godot 4.5 打开 `frontend/project.godot`，按 **F5 → 浏览楼层地图** 即可查看和试走。

1. 在 **Project → Load** 中打开上表对应的 JSON。改好后点 **Save**，用下载的工程文件替换 `map_sources/` 中的同名 JSON。[Sprite Fusion 在线编辑器](https://www.spritefusion.com/editor)
2. 如果改了门、楼梯等交互点的位置，先同步该楼层的 `manifest.json`。在仓库根目录打开 CMD，运行下列命令重建楼层。首次使用时先运行 `python -m pip install Pillow`，将 `FLOOR` 设为源图文件名（去掉 `.json`）。

   ```cmd
   set "FLOOR=jishilou_floor3"
   python frontend\tools\build_floor.py "map_sources\%FLOOR%.json" "frontend\assets\map\%FLOOR%"
   ```

3. 在 Godot 中试走确认，把源 JSON 和 `frontend/assets/map/<楼层>/` 中更新的文件一起提交。
